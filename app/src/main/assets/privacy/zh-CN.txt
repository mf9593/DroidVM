DroidVM 隐私协议
更新日期：2026年11月25日
生效日期：2026年11月25日

感谢你使用 DroidVM（以下简称「本应用」）。本应用在安卓设备上运行虚拟机。本构建是维护在 https://github.com/mf9593/DroidVM 的 fork，原项目为 https://github.com/Droid-VM/DroidVM。
本隐私协议说明：在使用需要联网的功能时，本应用如何收集、使用和保护你的信息。

一、信息的收集与使用
本应用默认不会收集任何个人信息。仅当你主动同意本协议后，才会发起以下网络请求。

1. 更新检查（GitHub）
本应用会访问 https://api.github.com/repos/mf9593/DroidVM/releases/latest（GitHub, Inc.），读取本分支的最新 release。请求会在 HTTP User-Agent 中携带应用版本，并按 HTTPS 的常规方式携带你的 IP 地址；该请求适用 GitHub 自己的隐私政策。本应用不会创建账号、发送设备标识，也不会在更新对话框和常规 HTTP 缓存之外保存响应。

2. 镜像、软件与 LXC 元数据（上游服务）
当你打开镜像下载索引、软件镜像列表或 LXC 镜像目录时，本应用会访问上游元数据 API https://api.classfun.cn/。该服务由 DroidVM 上游项目运营，不是本分支运营。请求会携带你的 IP 地址和 User-Agent（应用版本、Android 版本、设备型号、SoC 型号）；该请求适用上游运营方的访问日志与隐私政策。

二、信息的存储与共享
不存储：本应用不保存你的 IP 地址或 User-Agent；更新响应只保留用于避免重复下载的常规 HTTP 缓存。
不共享：本应用不会向任何第三方出售、交换或转让上述信息；请求直接发往上述 GitHub 或上游元数据服务。
不关联：本应用不会把上述信息关联到设备标识、账号或其他可识别身份的信息。

三、你的选择
同意协议：可以使用更新检查和在线元数据目录。
拒绝协议：本应用不会调用上述两个服务；更新检查和在线目录不可用，其他本地虚拟化功能不受影响。
你可以随时在应用设置中更改授权状态。

四、数据安全
请求使用 HTTPS。本应用不持久化上述技术信息；远端运营方按其自身政策处理各自的日志。

五、未成年人保护
本应用不面向 14 周岁以下未成年人。如你为 14 周岁以下，请勿同意本协议或使用依赖网络的功能。

六、协议变更
如发生重大变更（例如新增数据接收方），本应用会再次征求你的同意；措辞或地址的微小更新会直接更新本页面，并在需要重新同意时提升元数据版本号。

七、联系我们
如你对本协议有任何疑问，请在本分支提交 issue：
https://github.com/mf9593/DroidVM/issues

注意：本协议覆盖发往 GitHub 的更新检查和发往 https://api.classfun.cn/ 的元数据请求。DroidVM 本身作为本地虚拟机管理工具，不会收集设备文件、位置、联系人或其他敏感信息。

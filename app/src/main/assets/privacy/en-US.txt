DroidVM Privacy Policy
Last Updated: November 25, 2026
Effective Date: November 25, 2026

Thank you for using DroidVM (hereinafter referred to as "this Application"). This Application runs virtual machines on Android devices. This build is a fork maintained at https://github.com/mf9593/DroidVM; the original project is https://github.com/Droid-VM/DroidVM.
This Privacy Policy explains how this Application collects, uses and protects information when you use features that need a network.

I. Information Collection and Use
By default, this Application does not collect any personal information. Only after you explicitly agree to this policy will it make the network requests below.

1. Update check (GitHub)
The Application contacts https://api.github.com/repos/mf9593/DroidVM/releases/latest (GitHub, Inc.) to read the latest release of this fork. The request contains the Application version in the HTTP User-Agent and your IP address as part of any HTTPS connection. GitHub's own privacy policy applies to that request. The Application does not create an account, send a device identifier, or store the response beyond the update dialog and the normal HTTP cache.

2. Image, software and LXC metadata (upstream service)
When you open the image download index, the software mirror list or the LXC image catalog, the Application contacts the upstream metadata API at https://api.classfun.cn/. That service is operated by the DroidVM upstream project, not by this fork. The request contains your IP address and a User-Agent (Application version, Android version, device model and SoC model). The upstream operator's access logs and privacy policy apply to those requests.

II. Information Storage and Sharing
No Storage: this Application does not store your IP address or User-Agent. The only copy of the update response is the normal HTTP cache used to avoid repeated downloads.
No Sharing: this Application does not sell, exchange or transfer the information above to any third party. The requests go directly to GitHub or to the upstream metadata service described above.
No Association: the information is not associated with a device identifier, account or other identifiable information by this Application.

III. Your Choices
Accept the Policy: you may use the update check and the metadata catalogs.
Reject the Policy: this Application will not call either service. The update check and the online catalogs will be unavailable; local virtualization features remain unaffected.
You can change your choice at any time in the Application settings.

IV. Data Security
The requests use HTTPS. This Application does not persist the technical information described above; the remote operators handle their own logs under their policies.

V. Protection of Minors
This Application is not intended for individuals under the age of 14. If you are under 14, please do not agree to this policy or use network-dependent features.

VI. Policy Changes
If there are material changes (for example, a new data recipient), the Application will ask for your consent again. Minor wording or address updates are published on this page; the metadata version is bumped when consent is required again.

VII. Contact Us
If you have any questions about this Privacy Policy, please open an issue at:
https://github.com/mf9593/DroidVM/issues

Note: this policy covers the update check to GitHub and the metadata calls to https://api.classfun.cn/. As a local virtual machine manager, DroidVM does not collect device files, location data, contacts or other sensitive information.
